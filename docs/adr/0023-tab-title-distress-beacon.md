# Tab Title Distress Beacon

Users browsing other tabs cannot see in-page canvases or HUD overlays. We decided to implement the Tab Title Distress Beacon by dynamically prefixing `document.title` with fungal emojis, rot percentages (`🍄 (X%)`), and critical countdowns (`☠️ [Xs ROTTING TO DEATH!]`). This makes tab neglect visible across the native browser tab strip, prompting users to decontaminate hoarded tabs, and cleanly restores natural page titles upon sanitization.
