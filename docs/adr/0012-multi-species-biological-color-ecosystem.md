# Multi-Species Biological Color Ecosystem

Uniform monochromatic green rendering failed to reflect the natural visual complexity of real-world rotting surfaces. We decided to implement a multi-species fungal ecosystem featuring five distinct biological mold taxa: Penicillium (dusty turquoise/seafoam), Aspergillus niger (charcoal soot black), Aspergillus flavus (mustard ochre yellow), Neurospora (coral peach red), and Cladosporium (deep forest olive), each with characteristic core pigments, spore stippling, and exudate guttation colors.
