# Necrotic Purge Tab Termination with Grace Countdown

Closing hoarded tabs unconditionally risks catastrophic data loss and user frustration. We decided to implement Necrotic Purge: when Rot Progress reaches 100%, an emergency 10-second Critical Grace Countdown triggers with pulsing red HUD alarms, distress screen shakes, and red edge vignettes, allowing users to rescue the tab by scrubbing below 100%. Protective termination safeguards exempt pinned tabs, audible media, and pages with active form inputs, controlled by an opt-in toggle in the extension popup.
