# Biological Dendritic Hyphae and Satellite Colonies

Rendering mold via geometric line segments or flat solid polygons produced an artificial topographic camouflage appearance rather than realistic fungus. We decided to implement a biological spore-cluster engine: soft radial mycelium halos, velvety olive-black necrotic cores, granular micro-spore stippling with exponential density, feathery radiating whiskers, continuous water-seepage edge stains, and airborne mildew speckles. This delivers authentic fungal morphology while maintaining incremental 60fps canvas performance.
